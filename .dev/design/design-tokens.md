# 디자인 토큰 (3테마)

> 목업(mockups.html)에서 추출. 구현 시 테마별 색/모양을 이 토큰으로 분리한다.

## 공통
- 카드 radius: A/C 24~26dp, B 22dp
- 항목 row 세로 패딩: 12~14dp, 터치 영역 ≥ 48dp
- 시계: 시:분 큰 글씨(56~64sp), 날짜 14sp
- 완료 항목: 텍스트 취소선 + muted 색

## A · 다크 글래스
| 토큰 | 값 |
|------|-----|
| 배경 | linear-gradient(160°, #2b1f54 → #1a1438 → #0d0a1f) |
| 카드 | rgba(255,255,255,.10) + blur, 1px rgba(255,255,255,.14) 테두리 |
| accent (체크 채움) | #7c6cff |
| 텍스트 | #ffffff |
| muted (완료/날짜) | #8a85a8 / #b8b2d8 |
| 체크박스 | 라운드 사각(radius 8), 미완 외곽선 rgba(255,255,255,.5) |
