# LockTodo UIUX 개선 스펙

> 상태: 초안 (디자인 리뷰 4라운드 대상) · 작성 2026-06-07
> 배경: 기능(추가/삭제/체크)은 구현·검증 완료. 현재 UI 는 프로그래매틱 기본 위젯이라 디자인이 빠져 있음. 이 스펙은 시각/인터랙션 개선 범위를 정의한다.

## 1. 목표

- 3개 테마(A 다크 글래스 / B 라이트 미니멀 / C 따뜻한 카드)를 **사용자가 선택**할 수 있게 한다.
- **잠금화면에 시계**(시각 + 날짜)를 추가한다.
- 현재 UI 의 4대 문제를 해결한다:
  1. 삭제가 큰 회색 버튼 → 목록이 "버튼 리스트"로 보임
  2. 완료 항목 구분이 약함(○/✓ 텍스트)
  3. 권한/서비스 버튼이 화면 상단을 다 먹어 시각 위계가 거꾸로
  4. 여백·정렬·카드 없음

## 2. 비목표
- 기능 추가(날짜/우선순위 등) 없음 — 디자인/인터랙션만.
- 다국어, 다크모드 자동 전환(테마는 수동 선택).

## 3. 화면별 개선

### 3-1. 잠금화면 (LockActivity) — 핵심
- 상단 **큰 시계**(시:분) + 날짜(요일 포함). 1분마다 갱신.
- 할 일은 **카드** 안에 목록. 각 항목 = 체크박스 + 텍스트.
- **완료 항목**: accent 체크 + 텍스트 취소선 + 회색으로 죽임.
- 배경은 선택 테마(A 다크 그라데이션 / B 라이트 / C 크림).
- 잠금 해제 없이 체크 토글(기존 동작 유지).
- 할 일 없으면 빈 상태 문구(예: "오늘 할 일이 없어요").

### 3-2. 메인 (MainActivity)
- 상단: 앱 타이틀 + **테마 선택**(A/B/C 칩 or 세그먼트).
- 권한/서비스: 큰 버튼 3개 → **상단 안내 배너 1줄** 또는 설정 영역으로 축소(목록이 주인공).
- 할 일 입력: 깔끔한 입력 + 추가(아이콘 또는 작은 버튼).
- 목록: 카드/구분선, **삭제는 작은 ✕ 아이콘 또는 스와이프**(큰 회색 버튼 제거).
- 완료 상태 동일 스타일(취소선+회색).

## 4. 컴포넌트 규칙
- **체크박스**: 미완 = 외곽선, 완료 = accent 채움 + 흰 ✓. 테마별 모양(A/C 라운드 사각, B 원형).
- **카드**: radius 22~26, 테마별 배경(글래스/흰/반투명 크림).
- **항목 row**: 좌측 체크박스 + 텍스트, 우측 삭제(메인만). 터치 영역 ≥ 48dp.
- **accent 색**: 테마당 1개 (A 보라 #7c6cff / B 인디고 #4f6bed / C 코랄 #ff8a5c).
- **완료 텍스트**: 취소선 + 테마별 muted 색.

## 5. 테마 시스템
- 테마 3개를 디자인 토큰으로 정의([design-tokens.md](./design-tokens.md)).
- 선택 값은 저장(SharedPreferences). 메인·잠금화면 모두 반영.
- 구현: 테마별 색/모양을 토큰으로 분리해 한 컴포넌트가 토큰만 바꿔 렌더.

## 6. 구현 방향
- 현재 프로그래매틱 LinearLayout 의 한계가 큼 → **Jetpack Compose** 또는 **XML+Material3** 중 택1.
- 디자인 리뷰에서 구현 방식(Compose vs XML)도 함께 결정한다.

## 7. 완료 기준 (이 작업 전체)
- 디자인 리뷰 4라운드(4페르소나) 통과 → 스펙 확정
- 3테마 + 시계 + 4대 문제 해결 실구현
- 에뮬에서 테마 전환 + 시계 + 추가/삭제/체크 동작 확인
- devil review 4-pass 전원 통과

## 8. 결정됨 (Round 1, 상세는 decisions.md)
- 구현: **Jetpack Compose** (만장일치)
- 글래스: 진짜 blur 폐기 → **반투명 fill + border** (배경이 자체 그라데이션, API31 제약)
- 삭제: 메인 **✕ 아이콘 + Undo 스낵바**, 잠금화면엔 삭제 없음
- 테마 선택: **메인 상단 세그먼트(즉시 프리뷰)**, prefs 저장
- 시계: 시스템 12/24h 따름, OS 시각 일치, 부분 갱신
- 대비: 본문 ≥4.5:1, 큰글씨/컴포넌트 ≥3:1 — 완료는 취소선+불투명도

## 9. 검증 지표 (정량, devil 요구)
- 색 대비 토큰 쌍마다 계산 통과 / 인터랙션 row ≥56dp / 시계 무깜빡임 / 테마 전환 즉시 반영 / 추가·삭제(+Undo)·체크 회귀 없음(에뮬 실측)
